# `sys/syscall.h`

与 `include/os/syscall.h` 对应的裸 ABI 常量——请优先
使用上层封装，不要直接调 `syscallN`。

类：`SYS_IO=1 SYS_TIME=2 SYS_MEMORY=3 SYS_POWER=4
SYS_PROCESS=5 SYS_FS=6 SYS_SIG=7`。
主要子操作：`IO_READ/WRITE/GETCHAR/CURSOR_*`、
`TIME_GET/TIME_TO/TIME_SLEEP`、
`MEMORY_MALLOC/CALLOC/REALLOC/FREE`、
`PROC_GETPID/EXIT/YIELD/LIST/SET_FG/EXEC`、
`FS_OPEN/CLOSE/READ/WRITE/UNLINK/MKDIR/RMDIR/STAT/GETCWD/
CHDIR/RENAME/READDIR`、`SIG_KILL/SIGNAL/RETURN`。
`SYSFS_O_RDONLY/O_RDWR`、`PROC_STATE_*`。
