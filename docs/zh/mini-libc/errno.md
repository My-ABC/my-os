# `errno.h`

`extern int errno` —— 单个全局量（无 TLS；Ring 3 每进程
单线程）。库封装在失败时设置；裸 `syscallN` 不设置。
常量与 Linux 取值一致：`EPERM ENOENT ESRCH EINTR EIO ENXIO
E2BIG ENOEXEC EBADF ECHILD EAGAIN ENOMEM EACCES EFAULT EBUSY
EEXIST EXDEV ENODEV ENOTDIR EISDIR EINVAL ENFILE EMFILE ENOTTY
ETXTBSY EFBIG ENOSPC ESPIPE EROFS EMLINK EPIPE EDOM ERANGE ...`
（完整列表见头文件）。
