# MyOS Shell 命令参考

[English](../en/07-shell-commands.md) | 中文

本文档描述 `src/os/shell.c` 提供的交互式 Shell。Shell 每次读取最多 128 个
字符的行，按空白拆分为最多 16 个参数，然后在命令表中精确匹配分发。除下文
注明外没有其他选项开关。

## 提示符与路径

- FAT32 文件系统挂载后，提示符显示当前目录：`myos /dir > `；否则显示
  `myos > `。
- 磁盘命令接受绝对路径（`/dir/file`）和相对当前目录的路径。`.`、`..`
  组件会被解析，多个连续 `/` 会被合并。
- 文件名和目录名**区分大小写**：Shell 创建的名字通过 LFN 项保留原始大小写；
  没有 LFN 的旧条目仍通过大写 8.3 短名匹配。
- 解析后的路径超出内部缓冲区时，所有磁盘命令统一报 `Path is too long`。

## 命令一览

| 命令 | 参数 | 说明 |
|---|---|---|
| `time` | `[12\|24]` | 打印当前时间（RTC，北京时间），格式 `YYYY-MM-DD HH:MM:SS`。默认 24 小时制；`time 12` 使用 12 小时制并附加 `AM`/`PM`，`time 24` 显式指定 24 小时制。 |
| `panic` | — | 触发调试断点（`int3`），演示蓝屏 panic 路径。 |
| `svga_blue` | — | 通过 VBE 把屏幕填成蓝色；失败时回退到蓝色 VGA 文本屏。 |
| `echo` | `<text>...` | 把参数以单个空格连接后同时打印到屏幕和 COM1 串口。 |
| `reboot` | — | 通过 ACPI 重启机器。 |
| `shutdown` | — | 通过 ACPI 关机。 |
| `tick` | — | 打印 PIT tick 计数。 |
| `help` | — | 列出全部命令及一行说明。 |
| `clear` | — | 清空 VGA 文本屏幕。 |
| `hello` | `[name...]` | 无参数打印 `Hello, my-os!`；有参数打印 `Hello, <name>!`。 |
| `ring3` | — | 把内置的一个 Ring 3 进程映射并调度到后台运行。 |
| `ps` | — | 列出 Ring 3 进程：PID、状态（`READY`/`RUNNING`/`DEAD`）及前台标记。 |
| `fg` | `<pid>` | 恢复某进程的输出显示（转前台）。 |
| `bg` | `<pid>` | 隐藏某进程的输出（转后台）。 |
| `kill` | `<pid>` | 按 PID 终止进程。 |
| `elf` | — | 加载并运行内嵌在内核镜像里的 ELF32 演示程序。 |
| `disk` | — | 探测 ATA 主盘并挂载 FAT32 文件系统。 |
| `ls` | `[dir]` | 列出目录（默认当前目录）。目录名带 `/` 后缀和 `<DIR>` 标记；文件显示字节数。 |
| `cat` | `<file>` | 把文件内容打印到屏幕和串口，最多读取 64 KiB。 |
| `write` | `<file> <text>...` | 把给定文本（参数以空格连接，最多 1023 字节）写入文件，不存在则创建。 |
| `cp` | `[-r] <src> <dst>` | 复制文件。`-r` 时递归复制目录树（深度上限 32）。若 `dst` 是已存在的目录，则把源放入其中，即 `dst/<basename>`。`cp` 会覆盖已存在的目标文件；拒绝把目录拷进自身或其子目录。 |
| `mv` | `<src> <dst>` | 移动或重命名文件/目录。若 `dst` 是已存在的目录，则移入其中即 `dst/<basename>`。已存在的目标文件会被替换；已存在的目标目录会被拒绝。移动目录会更新其 `..` 项，并拒绝把目录移入自身子树。 |
| `rm` | `<file>` | 删除文件（仅文件；目录用 `rmdir`）。 |
| `cd` | `[dir]` | 切换当前目录（默认 `/`）。目录必须在已挂载的文件系统中存在。 |
| `mkdir` | `<dir>` | 创建目录；同名已存在时报错。 |
| `rmdir` | `[-f] <dir>` | 删除空目录。`-f` 时递归删除非空目录树。拒绝删除当前目录或其祖先目录。 |
| `run` | `<elf32-file>` | 从磁盘读取 ELF32 可执行文件并作为 Ring 3 进程运行。文件先读入 1 MiB 内核缓冲，因此受 `FAT32_MAX_FILE_SIZE` 限制。 |

## 注意事项与限制

- 没有 `rm -r`；递归删除用 `rmdir -f <dir>`。
- `write` 是整体覆盖写，没有追加模式。
- `cp -r` 会先把每层目录枚举到堆分配的列表里再复制，因为
  `fat32_list_directory` 遍历的是共享的静态缓冲区。
- 磁盘和进程类命令的输出同时写到 VGA 屏幕和串口，串口 socket 会话因此可以
  被脚本化驱动。
- Shell 内输入 `help` 是权威命令清单；本文档对应 `src/os/shell.c` 中的
  `cmd_table`。
